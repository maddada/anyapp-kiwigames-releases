# Kiwi Games

<img src="icon.png" alt="Kiwi Games" width="96" height="96">

An Android app made with Kiwimake.

Latest version: **1.0** (build 41), published 2026-11-20.

## Install

1. On your Android phone, open [kiwigames.apk](https://github.com/maddada/anyapp-kiwigames-releases/releases/latest/download/kiwigames.apk).
2. Android asks you to allow installing apps from your browser: allow it, then tap Install.
3. From then on the app tells you when a new version is out. Tap the notification to update.
